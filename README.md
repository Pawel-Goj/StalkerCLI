# StalkerCLI

Hey! This is a lightweight real-time system telemetry and GitHub monitoring dashboard built purely in Python using [Rich](https://github.com/Textualize/rich). 

---

## 🛠️ Quick Setup

Clone the repo and get it running locally in under a minute:

```bash
# 1. Clone the repository
git clone [https://github.com/Pawel-Goj/StalkerCLI.git](https://github.com/Pawel-Goj/StalkerCLI.git)
cd StalkerCLI

# 2. Spin up a virtual environment
python -m venv .venv

# 3. Activate it
# On Windows (PowerShell):
.venv\Scripts\Activate
# On macOS / Linux:
source .venv/bin/activate

# 4. Install it locally in editable mode
pip install --editable .

Once installed, just type this command anywhere in your terminal to fire up the dashboard:
stalker
